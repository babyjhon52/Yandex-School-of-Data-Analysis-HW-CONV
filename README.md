# Нейронная сеть с нуля (NN from Scratch)

Этот репозиторий представляет собой решение домашнего задания в рамках курса по машинному обучению от Школы Анализа Данных (ШАД). Основная цель проекта — глубокое погружение в архитектуру нейронных сетей через самостоятельную реализацию их ключевых компонентов на Python с использованием только библиотеки NumPy.

Проект охватывает создание базового фреймворка, который позволяет конструировать и обучать простые нейронные сети, включая слои, необходимые для современных сверточных архитектур.

## О проекте

Создание нейронной сети с нуля является важным упражнением для понимания фундаментальных принципов их работы. Вместо использования высокоуровневых фреймворков, таких как TensorFlow или PyTorch, здесь реализованы основные механизмы:

*   **Прямое распространение (Forward Pass)**: вычисление выхода сети для входных данных.
*   **Обратное распространение ошибки (Backward Pass)**: вычисление градиентов для обновления весов модели.

Этот подход позволяет наглядно увидеть, как данные и градиенты проходят через каждый слой сети.

##  Ключевые компоненты

В рамках этого проекта были реализованы следующие модули:

#### Основные слои:
*   `Linear`: стандартный полносвязный слой.
*   `ReLU`: слой с функцией активации Rectified Linear Unit.
*   `SoftMax` / `LogSoftMax`: слои для получения вероятностного распределения на выходе.

#### Сверточные слои:
*   `Conv2d`: слой двумерной свертки, являющийся основой для работы с изображениями.
*   `Flatten`: слой для преобразования многомерных тензоров в вектор.

#### Слои нормализации:
*   `BatchNorm2d`: слой батч-нормализации для стабилизации и ускорения обучения сверточных сетей. Он нормализует выходные данные предыдущего слоя перед передачей в функцию активации.

#### Механизмы обучения:
*   **Функции потерь**: реализована кросс-энтропия (`CrossEntropyLoss`) для задач классификации.
*   **Оптимизаторы**: базовые алгоритмы для обновления весов, такие как `SGD` и `Adam`.

##  Архитектура фреймворка

Каждый слой реализован как отдельный класс с двумя основными методами:
1.  `forward(input)`: принимает на вход данные и возвращает результат преобразования.
2.  `backward(output_grad)`: принимает градиент от последующего слоя и вычисляет градиенты для обновления весов текущего слоя, а также градиент для передачи на предыдущий слой.

Такая модульная структура позволяет легко комбинировать слои, создавая различные архитектуры нейронных сетей.
